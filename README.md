# Cleaner Hero

Serious game gratuit de [Taqt](https://www.taqt.com) pour faire découvrir la borne **TaqtOne**.
Vous êtes agent d’entretien dans un aéroport : gardez les sanitaires propres et la satisfaction des usagers au plus haut pendant une semaine.

**Jouer :** https://agoraopinion.github.io/CleanerHero/

- Jouable dans le navigateur, sur mobile et ordinateur, sans inscription
- Français, anglais, allemand, espagnol (`?lang=fr|en|de|es`)

## Contenu du dépôt

| Fichier | Rôle |
|---|---|
| `index.html` | Le jeu complet (un seul fichier, aucune dépendance à compiler) |
| `og-image.png` | Image d’aperçu pour LinkedIn et les réseaux sociaux |
| `favicon.svg`, `apple-touch-icon.png` | Icônes |
| `robots.txt`, `sitemap.xml` | Référencement |
